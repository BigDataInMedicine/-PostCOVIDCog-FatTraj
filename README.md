# -PostCOVIDCog-FatTraj

R-Scripts for the analysis of the trajectories of cognitive function and fatigue after a SARS-CoV-2 infection

The Scripts were created using R version 4.4.3 (2025-02-28 ucrt). Save the two subfolders "scripts" and "functions" on your computer. Run the scripts in the subfolder "scripts" in the order of their enumeration. Adapt the folder paths in the beginning of the scripts and check if any additional folders (e.g., for tables or plots) are required to store results. Custom functions are stored in the subfolder "functions". "Class colors" and "variable names" are only required for scripts 9 and 10 for formatting of tables and plots.
